# Specs

Artefatos de trabalho por feature/bug do fluxo `clientela-spec-driven` (ver `.claude/rules/workflow/spec-format.md`).

- `ROADMAP.md` — **fonte de trabalho dos agentes**: todos os itens do projeto com status; "continue o roadmap" executa o próximo elegível.
- `_templates/` — templates canônicos dos artefatos (spec, research, plan, tasks, progress, validate, review). Sempre partir deles.
- `bugs-backlog.md` — bugs conhecidos aguardando correção (`BUG-NNN`).
- `{slug}/` — uma pasta por feature/bug em andamento ou concluído; é o histórico de trabalho do projeto (a memória *durável* fica em `project-memory/`).
